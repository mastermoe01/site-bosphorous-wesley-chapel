# site-bosphorous-wesley-chapel

Demo website for **Bosphorous Turkish Cuisine – Wesley Chapel** (28330 Paseo Drive, Unit 105, The Shops at Wiregrass),
built by Raqm AI & Automation. Next.js App Router + React Three Fiber + Motion + Tailwind 4.

- Menu data: `lib/menu.json` (Wesley Chapel Toast menu, captured 2026-11-06).
- Facts: `lib/site.ts`. Photos: `public/photos/` (sources recorded in the studio's client folder).
- Videos: drop `public/videos/28330-paseo-dr/walkthrough.mp4` / `flyover.mp4` (+ `poster-*.jpg`); the Home section appears on the next deploy.
